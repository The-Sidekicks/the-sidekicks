UI styleguide · Edition 02
Start here

Build to the system, not the screenshots.

This page is the source of truth. Tokens, spacing, components and patterns all use the same named roles, so a change in one place is a change everywhere. The page works from file:// with no build step; the only external request is Google Fonts.

Brand layer vs editorial variant. The styleguide is the brand layer: ivory, ochre and ink. The live marketing site is a documented editorial variant using a warmer paper stock, a softer yellow, Georgia headlines and Inter body copy. Both are intentional; neither is a mistake to reconcile.

Focus, once

Interactive elements use a 2 px ink outline with a 3 px offset. The same treatment is applied to .btn; do not remove it without replacing it.

Focus sample

44 px targets

Primary and form buttons keep a 44 px minimum height at every width. Icon-only controls use a 44 × 44 px hit area even when the visible mark is smaller. Compact copy chips stay smaller by design and keep a visible focus ring.

44 × 44

Disabled stays legible

Disabled text on --disabled-fill is 8.50:1. WCAG exempts inactive controls, but the label still reads clearly; the muted ochre is what signals the state.

8.50:1
05 — Spacing & layout

Room to breathe,
everywhere.

A small scale, a friendly radius and a fixed page width. Between 600 px and 1200 px the page is fluid; below 600 px the gutter tightens to 24 px.

Spacing scale

Use the nearest step. Steps 1–6 cover component internals; 7–10 cover section rhythm.
